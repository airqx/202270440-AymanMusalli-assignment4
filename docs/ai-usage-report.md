# AI Usage Report - Assignment 4

## 1. Tools Used and Use Cases

### GitHub Copilot (Primary)
Used for:
- suggesting JavaScript logic patterns
- improving error handling
- assisting backend endpoint structure
- speeding up repetitive code writing

### ChatGPT (Secondary)
Used for:
- debugging guidance
- explaining integration and validation patterns
- improving documentation wording and structure

### Claude (Occasional)
Used for:
- alternative review suggestions for documentation clarity
- checking explanation quality for report sections

## 2. Benefits and Challenges

### Benefits
- Faster implementation of API and form workflows.
- Better coverage of edge cases through suggested validation patterns.
- Improved documentation structure and readability.
- Easier debugging with step-by-step troubleshooting ideas.

### Challenges
- Some generated suggestions were generic and needed project-specific adaptation.
- Not all suggestions were optimal for this codebase style.
- AI output still required manual testing and verification.

## 3. Learning Outcomes

### Technical Learning
- Improved understanding of frontend/backend API communication.
- Better validation strategy design (client + server).
- More confidence in handling asynchronous flows and error states.
- Stronger understanding of deployment environment differences.

### Workflow Learning
- Validate AI output before integrating.
- Prefer small, testable changes over large unverified changes.
- Use AI for acceleration, not replacement of reasoning.

## 4. Responsible Use and Modifications

I used AI as an assistant, then manually:
- reviewed code for correctness
- adjusted logic to match my HTML/CSS structure
- removed unnecessary complexity
- tested behavior in the browser and backend
- ensured the final submission reflects my own understanding

No raw AI output was submitted without review and modification.

## 5. Assignment 4 Contributions Supported by AI
- GitHub API integration flow and error handling patterns.
- Contact form validation and backend integration review.
- UI feedback flow improvements (loading states and notifications).
- Documentation quality improvements for the final project report and presentation preparation.

## Conclusion
AI tools helped speed up development and improve quality, but final architecture, verification, and code decisions remained my responsibility. The final solution was tested and adapted to meet assignment requirements and maintain academic integrity.
